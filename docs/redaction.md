- 按白名单复制 Skill、配套源文件和必要许可，没有复制整个用户配置目录。
- 小红书排除原数据库、文稿、真实素材、浏览器 profile、Cookie、登录二维码截图、历史日志和验收证据。

- 通用 Git 工作流内的公司域名示例替换为保留示例域名。具体业务地址、设备拓扑和专有协议条目只记录风险类别，未复制正文。
- 保留公开上游归属、原许可证与锁定源码哈希，不把第三方内容冒充自建。

## 后续检查

`scripts/check_export.py` 检查 Git 暂存区的实际 blob，不打印疑似秘密值：阻止运行数据/媒体/缓存、非文本文件、常见访问令牌/私钥、具体用户目录和私网 IPv4。公开上游的 `/` 用户路径示例只允许通用 user/example 占位。

该静态检查配合逐文件人工审查使用，不能识别所有业务秘密、所有自定义令牌或全部隐私形式。将来加入新文件时要重新审查来源、内容和依赖，不能仅依赖 `.gitignore`。

`scripts/package.py` 仅从检查通过的 Git 暂存区导出，压缩包不带 `.git`、提交身份、原历史或未暂存文件。每次导出都重新读取暂存 blob，并生成 SHA256SUMS。工作区修改必须重新暂存才会进入下一份包。

## 已知边界

13 个业务 Skill 仅列出待改造/暂缓结论。个人私有 GitHub 仍是仓库外目的地，不能据此直接迁移内部协议和业务材料。上传前会再次审核暂存快照，并核对目标仓库为个人私有。

小红书的可选上游源码附带更多工具，但未自动启用。本包没有复用账号进行真实搜索、上传或发布；新机器需要本人登录和验收。
